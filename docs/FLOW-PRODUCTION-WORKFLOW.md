# Next phase: Google Flow portfolio films

This is the production framework for the owner's next phase. No new film has been generated, uploaded or presented as completed brand work. Google Flow is not connected to this execution environment. Prompts below are production instructions for the Flow UI, not an invented command-line/API syntax. Available controls and clip lengths depend on the owner's account.

## Start with one product

Collect the brand/product name, original product photographs (front, back and useful angles), exact original logo, approved feature/benefit facts, audience, intended placement and desired tone. Confirm the scope of public use. Choose a short creator-style film, a cinematic product film, or a hybrid. Develop one coherent concept before generating variations.

Create a reference sheet that locks silhouette, proportions, material, colour, packaging layout, printed text, ports/buttons and logo placement. Do not use generated packaging as a replacement for the real product. If Flow cannot preserve a detail, use a generated environment and composite the original approved product/packshot in the edit.

## Recommended first portfolio set

1. A short UGC-style product explainer: one clear hook, a legible demonstration, one approved benefit and a restrained closing frame.
2. A CGI-style product reveal: a strong silhouette, controlled camera movement, original product detail and an accurate packshot finish.
3. Later, a hybrid film joining a human situation to one distinctive product visual.

These should be published as independent spec concepts with AI-assisted production disclosed. They must not imply the brand commissioned the work, that a synthetic person is a genuine customer, or that unmeasured campaign results exist.

## Shot prompt structure

Use a separate prompt for each shot. Keep camera movement and subject action simple enough to control. Generate clips at the durations offered in Flow, then trim them to the edit rather than assuming an exact duration control.

```text
PROJECT / [concept name]
SHOT / [number and editorial purpose]
FRAME / [vertical 9:16 or horizontal 16:9]
REFERENCE LOCK / Use the supplied approved product reference. Preserve the exact
silhouette, proportions, colour, packaging layout and original brand markings.
SUBJECT / [one subject, clearly described; fictional adult performer if required]
ACTION / [one specific, readable action]
SETTING / [specific location with an uncluttered background]
CAMERA / [framing, viewpoint and one controlled camera move]
LIGHT / [key-light direction, softness, practical highlights and palette]
TIMING / [opening state → main action → stable ending for the cut]
AUDIO / [room tone, simple sound cues; exact approved dialogue if appropriate]
CONTINUITY / [wardrobe, hand, product orientation, screen direction, set and light]
AVOID / Altered or invented logos, changed packaging text, additional ports or
buttons, duplicate products, deformed hands, flicker, warping, accidental text,
unsupported product claims, and unnecessary camera moves.
```

The reference lock is a review requirement, not a guarantee that a generation model will obey it. Inspect every usable frame at export size and reject or fix changes to the actual product.

## UGC edit blueprint

- Hook: a direct, relatable question or situation. Avoid a fabricated personal endorsement.
- Demonstration: one accurate action the product actually supports, with the label readable.
- Value: one verified benefit expressed plainly. Use only approved claims.
- Finish: original product and logo, with a simple call to action chosen for the concept.

Plan natural delivery, believable room lighting, restrained handheld movement, clean dialogue and comfortable pauses for the cut. Use a fictional adult character rather than recreating the owner's face without a separate instruction. Add accurate readable captions in the edit. Include spoken dialogue and visual context in the project description.

## CGI edit blueprint

- Reveal: silhouette and materials, one deliberate camera movement.
- Detail: an accurate feature or construction detail, with restrained motion.
- Hero: a distinctive environment that supports the product idea.
- Packshot: a stable original product/brand finish, composed for readable typography.

Use consistent scale, a defined key light, controlled reflections, plausible shadows and a limited palette. Add final typography, original logo artwork, timing and sound design during editing rather than asking generated text to carry the brand identity.

## Before publication

Check product/logo accuracy, anatomy and physical interactions, continuity, image artefacts, flicker, dialogue, rights to voice/music, captions, sound levels and clean export. Keep the original production references. Review on a phone as well as desktop. Export a browser-ready H.264 MP4; use the portfolio's `/manage` uploader and select the exact discipline. Use a title such as “[Product] — CGI concept” and begin the description with “Independent spec concept · AI-assisted production” when that is accurate. The description should state the concept, role, production method and spec status without claiming an unverified brand relationship or outcome.
